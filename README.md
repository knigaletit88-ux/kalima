# Калима — арабские карточки

Бесплатное приложение для детей и взрослых: арабские слова на карточках с голосом диктора, переводом на русский
и английский, картинками без людей и животных, девятью играми, дуа из «Крепости мусульманина» и 30-м джузом.
Без музыки и рекламы.

**Скачать последнюю версию для Android:**
https://github.com/knigaletit88-ux/kalima/releases/latest/download/Kalima.apk

Откройте скачанный файл и нажмите «Установить» (может понадобиться разрешить установку из этого источника).
Приложение само сообщает, когда выходит новая версия.
